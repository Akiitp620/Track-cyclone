# CycloneShield AI - Final Demo Script

**Total Time:** 3 minutes

### 0:00–0:20 — PROBLEM
"During a cyclone, knowing the storm path is not enough. Decision-makers need to know which infrastructure is exposed, which assets are most vulnerable, and what action should happen before impact."

### 0:20–0:50 — SCENARIO
*Action: Open Scenario Simulator.*
*Action: Change cyclone intensity, rainfall, and track shift.*
"This is a scenario simulation, not a replacement for official cyclone forecasting."
*Action: Show how the risk map changes in response.*

### 0:50–1:20 — IMPACT
*Action: Show critical infrastructure, high-risk assets, population exposed, access routes, and risk categories.*
"Our deterministic risk engine combines hazard, exposure, vulnerability and cyclone category."

### 1:20–1:50 — EXPLANATION
*Action: Open Gemini briefing.*
*Action: Show risk explanation, critical assets, reasons, and recommended actions.*
"Gemini does not calculate the risk score. It interprets the deterministic assessment and turns it into operational guidance."

### 1:50–2:20 — MULTIMODAL
*Action: Open Visual Evidence.*
*Action: Select demo visual evidence. Run multimodal analysis.*
"Gemini can also interpret visual evidence alongside the structured simulation context."
*(Note: Ensure demo evidence is visibly labelled DEMO if real Gemini credentials are unavailable).*

### 2:20–2:45 — GOOGLE STACK
*Action: Show Data & Method.*
"Earth Engine provides geospatial context. Gemini provides reasoning and multimodal interpretation. Vertex AI is the predictive-model layer, while BigQuery provides the scalable data layer for validated historical infrastructure-impact data."
*(Note: We explicitly disclose that Vertex AI and BigQuery are UNAVAILABLE until verified historical impact endpoints are active. They gracefully fallback out of the loop).*

### 2:45–3:00 — CLOSE
"Instead of stopping at 'a cyclone is coming', CycloneShield AI aims to answer the operational question: which infrastructure is exposed, why, and what should be done before impact?"
